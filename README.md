Rekey Quest

Rekey Quest é um jogo 2D desenvolvido pela Pudding Shadows, criado com Godot Engine.

«Um projeto indie em desenvolvimento, focado em exploração, desafios e mecânicas envolvendo portas e chaves.»

---

Sobre o projeto

Rekey Quest é um projeto independente desenvolvido pela Pudding Shadows.

O projeto possui diferentes sistemas e conteúdos organizados em áreas como:

- Jogabilidade
- Fases e níveis
- Portas e chaves
- Assets
- Sistemas e scripts
- Suporte a diferentes plataformas

---

Tecnologias

- Godot Engine 4.7
- GDScript

---

Estrutura do projeto

O projeto é organizado em diferentes diretórios para facilitar o desenvolvimento e a manutenção:

actors/
assets/
levels/
lobbies/
scenes/
scripts/
singletons/
portas e chaves/
tutoriais/

Também existem configurações e recursos específicos para diferentes plataformas.

Status
